# Memo

暗記アプリに入れる前の「とりあえずメモ」用アプリ。`index.html` をブラウザで開くだけで動きます。

- 入力すると日付が自動で付く（ジャンル別 / 日付別で表示切替）
- 英語・日本語を自動でジャンル分け（文・フレーズ / チャンク / 熟語・句動詞 / 動詞 / 名詞 / 形容詞 / 副詞 / スラング、日本語フレーズ / 動詞 / 形容詞 / 副詞 / 名詞）
- `honestly = 正直に` や `honestly 正直に` で意味も一緒に登録
- 間違ったジャンルはメモをタップして変更できる
- 暗記アプリに入れたら ○ をタップして「転記済み」に。「未転記をコピー」でまとめてコピー（単語<TAB>意味）
- 背景：アメリカの本物の動画（`videos/`）が自動で流れる。通信なしで動くアニメ（ニューヨーク / ルート66 / ゴールデンゲート）や、「🎬 自分の動画を選ぶ」で手持ちの動画も選べる

- テーマ: ミッドナイトネイビー（暗）/ ラベンダーミスト（明）

- 同期しない場合、データはブラウザ内（localStorage）だけに保存。ときどき「バックアップ保存」推奨
